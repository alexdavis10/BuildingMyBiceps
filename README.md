# Bicep Learning in 30 Days (Microsoft Docs Guided)

Welcome to a **personalized, day-by-day Bicep learning repository** designed to help you go from first deployment to production-ready patterns in 30 days.

This repo is intentionally aligned to **Microsoft Learn and Microsoft Docs** content for Azure Bicep.

## What you will learn

- Bicep fundamentals (syntax, parameters, variables, outputs, scopes)
- Core features (modules, loops, conditions, decorators, existing resources)
- Deployment workflows (CLI, validation, what-if, troubleshooting)
- Real-world project structure and reusable modules
- Governance-focused practices (tags, policy integration, role assignments)

## Prerequisites

- Azure subscription
- [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli)
- [Bicep tools](https://learn.microsoft.com/azure/azure-resource-manager/bicep/install)

## Recommended learning cadence

- **Days 1–10**: Fundamentals
- **Days 11–20**: Features and composition
- **Days 21–30**: Sample projects, validation, and production habits

If you follow one day at a time, you'll complete a practical Bicep learning journey in one month.
