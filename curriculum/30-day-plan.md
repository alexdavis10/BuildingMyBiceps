# 30-Day Bicep Learning Plan (Microsoft Docs)

This plan is organized into three phases:

- **Phase 1 (Days 1–10): Fundamentals**
- **Phase 2 (Days 11–20): Features and reusable architecture**
- **Phase 3 (Days 21–30): Project delivery and operational excellence**

Each day has a dedicated file in `days/` with:

- Learning objective
- Microsoft Docs reading list
- Hands-on task
- Reflection prompt
