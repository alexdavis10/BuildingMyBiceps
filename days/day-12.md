# Day 12 — Module parameter and output design

## Objective
Build confidence with **module parameter and output design** using official Microsoft guidance and a short practical exercise.

## Microsoft Docs reading
- https://learn.microsoft.com/azure/azure-resource-manager/bicep/modules
- https://learn.microsoft.com/azure/azure-resource-manager/bicep/outputs

## Hands-on task
1. Read the docs above and summarize the key concepts in your own words.
2. Apply one change in `projects/features-lab` connected to today's topic.
3. Run a validation command (`az deployment group what-if` or `az deployment group validate`) for your test resource group.

## Reflection prompt
- What concept from today reduces deployment risk the most for your environment?
- What naming, parameter, or module change would improve reusability?
