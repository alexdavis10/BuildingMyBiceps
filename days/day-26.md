# Day 26 — Tags and governance-ready design

## Objective
Build confidence with **tags and governance-ready design** using official Microsoft guidance and a short practical exercise.

## Microsoft Docs reading
- https://learn.microsoft.com/azure/azure-resource-manager/management/tag-resources
- https://learn.microsoft.com/azure/governance/policy/overview

## Hands-on task
1. Read the docs above and summarize the key concepts in your own words.
2. Apply one change in `projects/capstone-platform` connected to today's topic.
3. Run a validation command (`az deployment group what-if` or `az deployment group validate`) for your test resource group.

## Reflection prompt
- What concept from today reduces deployment risk the most for your environment?
- What naming, parameter, or module change would improve reusability?
