# Day 05 — Scopes and deployment targets

## Objective
Build confidence with **scopes and deployment targets** using official Microsoft guidance and a short practical exercise.

## Microsoft Docs reading
- https://learn.microsoft.com/azure/azure-resource-manager/bicep/deploy-to-resource-group
- https://learn.microsoft.com/azure/azure-resource-manager/bicep/deploy-to-subscription

## Hands-on task
1. Read the docs above and summarize the key concepts in your own words.
2. Apply one change in `projects/fundamentals-lab` connected to today's topic.
3. Run a validation command (`az deployment group what-if` or `az deployment group validate`) for your test resource group.
